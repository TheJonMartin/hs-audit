# Audit Checklist: Items HubSpot's API Cannot Share

## What

A short set of screenshots and answers for the parts of your portal the audit cannot read automatically. Together with the key, this replaces the live screen-share. Everything here is labelled "verbal" in our report because it comes from you, not the API.

Return this as a folder of screenshots plus the filled-in intake form. If an item does not apply, write "N/A". If something is hard to find, write "not sure" and we will work it out together.

## How

Tick each item as you go. Where we ask for a screenshot, include the full list (scroll or expand to show every row) and any column named.

### Intake form (answer in writing)

- [ ] Company name and industry
- [ ] Which HubSpot hubs you use and the tier of each (Starter, Professional, Enterprise)
- [ ] How long you have been on HubSpot
- [ ] Who manages HubSpot day to day: a dedicated admin, or someone with other main duties?
- [ ] The main problem or concern that led to this audit
- [ ] Which external tools you use for reporting or integrations, if any

### 1. CRM Foundation

- [ ] Settings, Users and Teams: screenshot of the user list showing **name, role and last login date**
- [ ] Do you have a sandbox account connected to this portal? (yes / no)
- [ ] Settings, Objects, Deals, Pipelines: for each pipeline, which properties are **required** at each stage (screenshot, or "none")

### 2. Lead Management

- [ ] Which forms are live on your website today (list the form names)

### 3. Sales Process

- [ ] Automation, Sequences: screenshot showing **name, status, total enrolled, open rate, reply rate**

### 4. Marketing

- [ ] Marketing, Ads: connected ad accounts and their sync status
- [ ] Settings, Marketing, Email, Subscriptions: is a preference center published? (screenshot)

### 5. Reporting

- [ ] Reports, Dashboards: full list showing **name, owner, number of reports, last viewed**
- [ ] Reports, Reports, All Reports: full list showing **name, owner, type, last modified**
- [ ] Screenshots of your main sales dashboard, marketing dashboard and leadership dashboard, if they exist
- [ ] Are any reports or dashboards maintained outside HubSpot (Excel, Sheets, Looker, other)? Which?

### 6. Workflows

- [ ] Automation, Workflows: filter to workflows with errors and screenshot the error details (or "no errors shown")
- [ ] Workflow list showing **enrolled in the last 30 days** and **error status**, if you can add those columns

### 7. Integrations

- [ ] Settings, Integrations, Connected Apps: list showing **app name, status, last sync**
- [ ] For any app with a sync error: screenshot of the error details
- [ ] Settings, Integrations, Private Apps and Service Keys: list showing **name, created date, last activity**

### 8. Billing (subscription businesses only)

- [ ] Is your billing system syncing to HubSpot? Any known sync problems? (answer, plus error screenshot if any)

### 9. Privacy

- [ ] Settings, Privacy and Consent: full page screenshot
- [ ] For three to five active forms: screenshot showing whether a consent checkbox or privacy notice is present

### 10. Adoption

- [ ] Uses the user list from Category 1 (no extra item)

## Done

You are done when every box is ticked or marked "N/A" or "not sure", and the screenshots and intake form are in one folder sent to your Process Pro contact. We will confirm receipt and tell you if anything is unreadable.
